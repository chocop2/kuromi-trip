## ✨ 뭐 하는 앱인가요

코타키나발루 갈 때 "여기 어디지, 어떻게 가지"를 매번 검색하기 귀찮아서 만든 플래너예요.
가고 싶은 곳 21개를 한 페이지에 모아두고, 카드를 누르면 **바로 아래 지도가 그 자리로 이동**해요.

| | 기능 |
|---|---|
| 🗺️ | **인앱 지도** — 카드를 누르면 페이지 안 지도가 바로 그 장소로 이동 |
| 📍 | **지도 버튼** — Google 지도 앱에서 장소 열기 |
| 🧭 | **길찾기 버튼** — 지금 내 위치에서 그곳까지 경로 바로 안내 |
| 🏷️ | **카테고리 탭** — 관광지 / 맛집 / 카페 / 테마 필터 |
| 💌 | **링크 복사** — 친구한테 한 번에 공유 |

## 📱 쓰는 법

1. 위의 **[앱 열러 가기](https://chocop2.github.io/kuromi-trip/)** 를 눌러요
2. 위쪽 탭으로 **관광지 / 맛집 / 카페 / 테마** 를 골라요
3. 궁금한 카드를 누르면 **위 지도가 그 장소로 이동**해요
4. **📍 지도** 로 자세히 보고, **🧭 길찾기** 로 지금 위치에서 출발해요
5. 맨 아래 **💌 링크 복사하기** 로 친구한테 보내요

> 💡 폰에서 브라우저 메뉴 → "홈 화면에 추가" 하면 앱처럼 쓸 수 있어요.

## 🗂️ 파일

```
kuromi-trip/
├── index.html              ← 사이트 첫 화면 (앱으로 연결)
├── Emily_Travel.html       ← 플래너 본체
└── 여행 앱 만들기/
    ├── Emily_Travel.html   ← 작업본
    └── 쿠로미.webp          ← 로고 이미지
```

**기술** · 순수 HTML/CSS/JavaScript 한 파일. 빌드 도구도, 프레임워크도 없어요.
폰트는 [Jua](https://fonts.google.com/specimen/Jua), 아이콘은 [Font Awesome](https://fontawesome.com/), 지도는 Google Maps Embed.
